# QA Best Practices Documentation

This is the documentation no team should have to figure out from scratch after a production outage. If you've ever spent 3 hours debugging only to realize it was a missing test case that nobody wrote because "we assumed QA had that covered," this doc is for you.

## Why This Exists

Every SaaS company needs solid QA documentation. Not "documentation" in the corporate sense—fake docs that exist because an auditor asked for them. Real documentation that saves your team time, prevents bugs, and makes onboarding less painful.

This folder contains our battle-tested standards for:

- **Test Case Standards** - What good test cases actually look like
- **Test Automation Standards** - How to write automation that doesn't become technical debt
- **Shift-Left Testing** - Moving testing earlier in the cycle (and why it matters)
- **AI-Enhanced Testing** - Using generative and agentic AI without losing your mind
- **Process & Workflows** - How testing fits into your development lifecycle
